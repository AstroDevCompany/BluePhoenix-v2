# BluePhoenix user guide

BluePhoenix is a project manager for developers (and for anything else you work on, like university courses). It keeps your projects, git state, commands, to-dos and time in one place, so switching between projects is fast.

**Start here**

1. [Getting started](getting-started.md): install BluePhoenix and add your first project
2. [The dashboard](dashboard.md): what the project cards show and do
3. [Projects](projects.md): add, edit, favourite and remove projects

**Everyday work**

- [Git](git.md): status, fetch, pull, push, branches, commits, stashes
- [Editors, terminals and commands](editors-terminals-commands.md): open a project anywhere, run build commands
- [To-dos and pages](todos.md): lists, Markdown notes, priorities
- [Time tracking](time-tracking.md): one-click time logging
- [Files](files.md): browse and open any file in your project
- [Changelogs](changelog.md): release notes from your git history

**Smart features**

- [Cloud sync and the iPhone app](sync.md): keep everything in step on all your devices
- [AI features](ai.md): local models (Ollama, LM Studio, llama.cpp) and cloud providers
- [Command palette](command-palette.md): do anything from the keyboard
