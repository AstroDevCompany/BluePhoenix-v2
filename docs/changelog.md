# Changelogs

Open a project's **Changelog** tab. It reads your git history, so you need a git project, and an [AI provider](ai.md) set up.

1. Choose which commits to include: the last 15, 30 or 100, or everything **since a tag** (for example `v1.2.0`).
2. Optionally edit the heading, such as *v1.3.0 - 2026-10-18*.
3. Pick an action:
   - **Generate changelog** writes release notes grouped as Added, Changed, Fixed and Removed.
   - **Summarize changes** gives a short bullet summary for a busy reader.
   - **Write PR description** drafts a pull-request description.
4. **Copy Markdown** and paste it into your release, CHANGELOG file or pull request.

The commits list on the left shows exactly what the AI sees.
