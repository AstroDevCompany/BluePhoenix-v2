# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘K` / `Ctrl+K` | Open the command palette |
| `Esc` | Close the palette, a menu or a dialog |
| `Enter` in the to-do box | Add the to-do |
| `Enter` in the palette | Run the selected action |
| `↑` `↓` in the palette | Move the selection |

The terminal behaves like your normal terminal, so its usual shortcuts work (`Ctrl+C`, `Ctrl+L`, history with `↑`).
