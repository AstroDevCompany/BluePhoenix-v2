# Command palette

Press **⌘K** (Mac) or **Ctrl+K** (Windows, Linux), or click the search box in the top bar. Type to filter, **↑ ↓** to move, **Enter** to run, **Esc** to close.

## What you can do

- **Jump** to any project, the dashboard, or Settings.
- When you are inside a project:
  - Fetch, pull, push, stash, apply stash
  - Open in your default editor, any installed editor, the embedded terminal, or any terminal
  - Run any of the project's commands
  - Log 10, 15, 30, 60 or 120 minutes
  - Go to a tab (Git, To-dos, Time, …)
  - Reveal the folder, open GitHub or the website, toggle favourite
- **General:** add a project, fetch all projects, refresh git statuses, switch theme, check for updates.
