# Settings

Open **Settings** from the top bar.

## Appearance

- **Theme:** System, Light or Dark.
- **Accent colour:** five colour pairs for buttons and highlights.

## Editors & terminals

Your default editor and terminal, and where the **Run** buttons start commands (embedded or system terminal).

## AI

Local or cloud provider, model, API key. See [AI features](ai.md).

## Cloud sync

Connect your own database to keep projects, to-dos and time in sync across your computers and iPhone. See [Cloud sync and the iPhone app](sync.md).
