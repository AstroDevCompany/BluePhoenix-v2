# Files

The **Files** tab lists every file in a project folder (files ignored by `.gitignore`, `.git` and `node_modules` are left out).

- **Search** matches any part of the path.
- **Click** a file to open it in your default editor. Hover for a button that reveals it in Finder or Explorer.
- Press **Refresh** after adding or removing files. BluePhoenix indexes up to 100,000 files per project.

The list is built the first time you open the tab.
